## 1. (Optional) Rebuild the portrait from a different photo

**Your real portrait is already built into `ascii.svg`.** You only need this
section if you want to use a different photo. The portrait is a one-off artifact,
so it is **not** on the daily schedule; you run its generator by hand.

The exact command used for the shipped portrait (source at
`scripts/portrait-source.jpg`):

```bash
# one-time deps for the portrait (background removal + image processing)
pip install pillow numpy opencv-python-headless rembg onnxruntime

python3 scripts/make_portrait.py scripts/portrait-source.jpg \
        --crop 240,40,670,600 --curve 1.25 --clahe 2.5
python3 scripts/embed_portrait_font.py
```

To use a new photo, drop it in (e.g. `scripts/portrait-source.jpg`) and rerun
those two commands, adjusting the flags:

- `--crop LEFT,TOP,RIGHT,BOTTOM` (pixels) frames head-and-shoulders. Open the
  photo, read the four pixel coordinates, pass them in. Omit to use the whole image.
- `--curve` is the darkening exponent (default 1.7; the shipped photo used 1.2
  because its light is softer/frontal). Lower = lighter. `--clahe` tunes local
  contrast (lower = less skin-texture noise). `--gamma` tunes the ramp mapping.
- The first run downloads a ~176 MB background-removal model, once. If the photo
  already has a clean white background, add `--no-remove-bg` to skip it.
- **Photo tips** (this is 90% of the result): side light, a tight crop from chin
  to just above the hair, and real resolution. More notes at the top of
  `scripts/make_portrait.py`.

Verify it looks right:

```bash
python3 scripts/verify_svgs.py          # XML valid + every glyph embedded
```

To preview the whole page as GitHub will render it (SVGs inside `<img>`), open
`preview.html` in a browser.

`assets/make_placeholder.py` (and any `assets/placeholder.png`) is only the
stand-in generator from before your real photo was added; you can delete it.
`assets/ascii-preview.png` is just a rendered preview of the portrait and is not
used by the page; delete it if you like.

## 3. Run the stats Action once (required)

Until the scheduled job runs, the committed stats are **sample numbers**. Kick
off a real run immediately:

**GitHub -> your repo -> Actions -> "refresh stats" -> Run workflow.**

After that it runs itself daily (05:17 UTC) and commits only what changed. It
uses the Actions-provided `GITHUB_TOKEN`, so **no secret is required** for public
contribution stats.

---

## 4. (Optional) Include private-contribution stats

The Actions `GITHUB_TOKEN` sees **public** contributions only. To count private
ones:

1. Create a **classic** personal access token with the **`read:user`** scope
   (add `repo` too if you want language totals from private repos).
   GitHub -> Settings -> Developer settings -> Personal access tokens -> Tokens (classic).
2. Save it as a repo secret named **`STATS_TOKEN`**
   (repo -> Settings -> Secrets and variables -> Actions -> New repository secret).
   The workflow already prefers `STATS_TOKEN` when present.
3. Enable **Settings -> Public profile -> "Include private contributions on my
   profile"** on your GitHub account.

## How the pieces fit

| File | Role |
| ---- | ---- |
| `ascii.svg` | the portrait (generated once, from your photo) |
| `stats.svg` `streak.svg` `langs.svg` `year.svg` | daily stat graphics |

| `scripts/subset_fonts.py` | builds the inlined JetBrains Mono subsets |
| `scripts/verify_svgs.py` | checks XML validity + glyph coverage |
| `.github/workflows/stats.yml` | runs `generate_stats.py` daily |
| `assets/fonts-src/` | full JetBrains Mono TTFs (source for the subsets, OFL) |
